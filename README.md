# Encryption/Decryption of Enigma Machine

Розв'язок задачі CodinGame [Encryption/Decryption of Enigma Machine](https://www.codingame.com/training/easy/encryptiondecryption-of-enigma-machine) (Easy) мовою Python 3.

## Умова коротко

На вхід подається:
1. операція: `ENCODE` або `DECODE`;
2. стартовий зсув `N`;
3. три ротори (рядки по 26 великих англійських літер);
4. повідомлення.

## Як працює

**Шифрування (ENCODE):**
1. Зсув Цезаря з наростаючим кроком: перша літера зсувається на `N`, друга на `N+1`, третя на `N+2` і т.д. (за модулем 26).
2. Результат по черзі проходить через ротори I, II, III: літера з позицією `k` в алфавіті замінюється на `k`-ту літеру ротора.

**Розшифрування (DECODE)** робить усе навпаки: спершу обернені ротори в порядку III, II, I (шукаємо позицію літери в роторі і беремо літеру алфавіту з цією позицією), потім зсув Цезаря у зворотний бік на `N+i`.

## Криптографічні примітиви

- **Зсув (shift)** — це зсув кожної літери по колу алфавіту на величину `N+i`, як у шифрі Цезаря. Оскільки крок росте з кожною позицією, однакові літери шифруються по-різному (`AAA` → `EFG` при `N=4`), тобто це вже не простий моноалфавітний шифр.
- **Заміна (substitution)** — кожен ротор є таблицею підстановки: кожній літері алфавіту ставиться у відповідність інша літера. Три ротори підряд — це три послідовні таблиці замін, що разом дають одну складнішу підстановку.

У справжній Енігмі ротори ще й обертаються після кожної літери, а сигнал проходить через рефлектор, тут це спрощено: роль «руху» виконує наростаючий зсув.

## Запуск

```
python3 enigma.py < input.txt
```

Приклад:
```
ENCODE
4
BDFHJLCPRTXVZNYEIWGAKMUSQO
AJDKSIRUXBLHWTMCQGZNPYFVOE
EKMFLGDQVZNTOWYHXUSPAIBRCJ
AAA
```
Вихід: `KQF`. Перевірено також `WEATHERREPORTWINDYTODAY` (N=7) → `ALWAURKQEQQWLRAWZHUYKVN` і зворотне розшифрування.
